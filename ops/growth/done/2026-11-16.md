## G-20261116-3 — newsletter join source (done, in the PR)
`NewsletterSignup.astro` takes a `source` prop (`home`, `guide`, `newsletter-page`, `retreat-match`). On submit it sends `fields[signup_source]` = `<placement>:<page path>` to MailerLite and adds `signup_source` to the Analytics `sign_up` event. If MailerLite rejects the submission because that field does not exist, the script retries without it, so joins cannot break. The field is added by script only, so the no-JS fallback is unchanged.
Adam must do one thing for MailerLite to store it: create a custom text field with key `signup_source` (Subscribers → Fields). Until then the Analytics event still carries the source.
